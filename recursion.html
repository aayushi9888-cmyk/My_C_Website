2.write a program of recursion with global varaiable and display the output

Source Code

#include <stdio.h>
int n = 1;
void display()
{
if(n <= 5)
{
printf("%d ", n);
n++;
display();
}
}
void main()
{
display();
}

Output

1 2 3 4 5
