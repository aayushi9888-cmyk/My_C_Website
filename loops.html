Source Code

{

24. Enter a number from user and check it is Armstrong number or not

Source Code

#include <stdio.h>
void main()
{
int n, temp, rem, sum = 0;
printf("Enter a number: ");
temp = n;
for(; n > 0; n = n / 10)
{
rem = n % 10;
sum = sum + rem * rem * rem;
}
if(sum == temp)
printf("Armstrong number");
else
printf("Not an Armstrong number");
}

Output

Enter a number: 153
Armstrong number
